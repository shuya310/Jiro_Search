# ラーメン二郎 直系店マップ

現在地から近い順にラーメン二郎の直系店を表示するiOSアプリです。

## 機能

- 📍 現在地から各店舗までの距離を表示
- 🕒 営業時間の表示（営業中/営業時間外）
- 🔍 営業中の店舗のみをフィルタリング
- 📱 距離順に自動ソート

## シミュレータでのテスト方法

シミュレータでは実際のGPSが使えないため、位置情報を手動で設定する必要があります。

### 方法1: 東京の位置を設定

1. シミュレータを起動
2. **シミュレータのメニューバー** → **Features** → **Location** → **Custom Location...**
3. 以下を入力:
   - **Latitude (緯度)**: `35.6812`
   - **Longitude (経度)**: `139.7671`
4. **OK** をクリック
5. アプリを再起動

### 方法2: プリセット位置を使用

- **Features** → **Location** → **Apple** (カリフォルニア)
- **Features** → **Location** → **City Run** (動的に変化)

### 注意事項

- 位置情報が取得できない場合、自動的に東京駅の座標がデフォルトとして使用されます
- 初回起動時は位置情報の許可ダイアログが表示されます
- シミュレータで位置情報を変更した場合、アプリ内で自動的に距離が再計算されます

## 実機でのテスト

実機では実際のGPSが使用されるため、特別な設定は不要です。

1. 位置情報の許可を「使用中のみ許可」で許可
2. アプリが自動的に現在地を取得
3. 現在地から各店舗までの距離が表示されます

## トラブルシューティング

### 距離が表示されない

- 位置情報の許可を確認してください
- シミュレータの場合、位置情報が設定されているか確認してください
- コンソールログで「⚠️ 位置情報が取得できませんでした」が表示されている場合、デフォルト位置（東京駅）が使用されます

### 距離が8000km以上表示される

- シミュレータの位置情報がサンフランシスコなど海外になっている可能性があります
- 上記の「シミュレータでのテスト方法」を参考に、日本の位置情報を設定してください

## 技術スタック

- Swift
- SwiftUI
- CoreLocation（位置情報）
- MapKit（ジオコーディング）

## データについて

店舗の営業時間は変更される可能性があります。必ず各店舗の公式SNS（Xアカウント）で最新情報を確認してください。
